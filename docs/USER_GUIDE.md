# 玄凤 · DesktopCock 使用说明

Windows 10/11 x64 桌宠。解压后运行 `DesktopCock.exe`，保留同目录 Assets 和运行库。更新时从托盘退出旧进程，再运行新包；Debug 与 Release 共用单实例约束。

## 日常互动

- 按 `Alt+1` 切换接鸟手型，按 `Alt+2` 切换摸头手型；数字区与小键盘均支持。按住 Alt 再按 Esc 下方的反引号／`·` 键恢复正常鼠标。组合键不同时带 Ctrl、Shift、Win；快捷键全局生效，单独输入数字或反引号不会切换手型。按键仍传递给前台程序。
- 手型出现后，小鸟优先转头盯着手，上移会抬头，持续在较远后方停留会踏步转身。恢复鼠标后立即丢失手型注意力，普通悬停不会重新吸引它。
- 接鸟手指靠近脚边停留约 0.4 秒，小鸟先抬脚再站上手，随后跟着鼠标移动。换成摸头手型或恢复鼠标时，会飞往距离最近且未被遮挡的可站位置；没有合适的平台就回任务栏。移动到主屏安全范围外也会离手。
- 摸头手指靠近头部，小鸟先低头，约 0.3 秒后进入抚摸，无需点击或按住左键；移开手就结束抚摸。手型期间鼠标点击穿透小鸟。
- 正常鼠标仍可在头部按住左键并缓慢来回移动摸头；连续点击、快速揉搓或摸得太久会惹它生气并啄咬。
- 白天空闲 10 分钟睡觉，22:00–07:00 空闲 2 分钟睡觉；恢复键鼠输入后醒来伸翅。点击睡鸟会增加烦躁。
- 鸟会散步、低头求摸、眨眼、轻叫和吹口哨。走路步频跟随实际移动距离；叫声的嘴部张合跟随实际播放进度。

## 托盘与飞行

托盘右键可隐藏、暂停、改变大小、切换羽色、开关自主飞行、调整探索间隔或退出；双击恢复显示。图标可能位于 Windows 托盘折叠菜单中。羽色提供原始灰、黑牛（白脸原始）和黄化，切换后保存并在下次启动恢复。

默认每 90 秒考虑飞往稳定、足够宽的平台，探索间隔可设为 5–3600 秒。识别依据是画面形状，窗口、卡片和图片中的横向树枝都可能成为落脚点。睡觉、摸头、手型模式时延后探索；起飞后暂不接受上手或地面摸头。关闭自主飞行也不影响离手后的最近落点选择。

停栖后跟随平台的窗口移动和内容滚动；平台失效时寻找其他落点，无合适目标则回到任务栏。关闭「自主飞行」可停止探索。

暂停、隐藏、锁屏或全屏隐藏会退出手型并恢复系统光标；恢复活动后，原先站在手上的小鸟飞向有效落点。程序正常退出时恢复原光标。

## 范围与设置

当前支持主屏上的一只宠物；任务栏自动隐藏时落在屏幕底边，侧边任务栏或读取失败时使用主屏工作区底边。全屏应用与锁屏期间隐藏并停止感知和声音。鸟声默认 35% 音量，托盘「声音」可静音；运行时无联网、开机启动、跨屏拖动或鼠标轨迹记录。

托盘「教它说话…」支持按住录音、松开后本地识别与记忆，也可主动开启仅在教学窗口打开期间有效的自动学习。麦克风默认关闭，关闭教学窗口即停止；记录可删除。首次需运行项目的 `tools/setup_speech.ps1` 安装离线组件，详见 [音频说明](AUDIO.md)。当前尚无任意人声转玄凤的合格模型；已学短语只有导入你认可的玄凤示范后才会复述。

屏幕识别使用 DXGI 桌面复制和 D3D11 Compute Shader，全屏搜索最多 2 Hz、当前平台局部追踪最多 60 Hz。截图只在内存／显存处理，不保存或上传；GPU 捕获不可用时保留任务栏模式并自动重试。

正式版设置位于 `%LOCALAPPDATA%\DesktopCock\settings.json`；Debug 使用 `%LOCALAPPDATA%\DesktopCock.Debug\settings.json`。通过托盘修改大小、羽色或飞行设置会自动保存。退出后可以手动修改参数，再启动生效。兼容原有平铺 JSON，缺少字段使用默认值；无法读取或解析时恢复默认并在同目录 `error.log` 记录原因。

| 设置字段 | 默认值与范围 |
| --- | --- |
| `Scale` | `3`，支持 2／3／4 倍 |
| `Skin` | `original`；另有 `whiteface`、`lutino`，未知标识回退原始灰 |
| `AutoExploreEnabled` | `true` |
| `ExploreIntervalSeconds` | `90`，范围 5–3600 秒 |
| `AudioMuted` | `false`；托盘静音开关 |
| `AudioVolume` | `0.35`，范围 0–1 |
| `AudioVisualDelayMs` | `0`，范围 0–500 毫秒；用于输出设备的口型延迟校准 |

正式版不包含开发面板。Debug 包另附 `DEBUGGING.md`，提供观察室、飞行覆盖层及验证入口。
