# 默认行为规则

当前为优先级决策策略加动作状态机，尚未引入行为树框架或新的评分玩法。

| 顺序 | 规则 |
| --- | --- |
| 1 | 平台失效等运动安全规则优先；飞行期间暂停地面决策 |
| 2 | 睡眠中恢复键鼠输入或被点击，进入 1 秒伸翅 |
| 3 | 伸翅和 0.4 秒啄咬未结束时保持动作；点击仍可积累烦躁 |
| 4 | 手型会话优先保持注意力；接鸟手在脚边停留 0.4 秒先 Lift 后上手随动，摸头手在头部附近先 Beg、0.3 秒后 Pet；移开则 Look |
| 5 | 无手型、无直接互动且系统空闲达到阈值，睡眠；白天 600 秒，22:00–07:00 为 120 秒 |
| 6 | 根据语义抚摸质量积累确认时间与烦躁；烦躁达到 60 且鼠标附近、冷却 3 秒后啄咬 |
| 7 | 温和抚摸确认 0.3 秒后进入 Pet；过久或粗暴抚摸按原参数积累烦躁 |
| 8 | 普通鼠标仅在点击／按住时提供注视目标；普通悬停不吸引注意力，退出手型立即清除注意力 |
| 9 | 原有走路、求摸、唱歌未结束时继续 |
| 10 | 满足直接互动间隔、唱歌冷却与概率后唱歌；否则按活动计时选择站立、走路、求摸 |

普通鼠标点击 +15，睡眠点击 +60；鼠标按住快速抚摸每秒 +20，累计温和抚摸超过 8 秒后每秒 +10。无直接互动时按每秒 10 恢复；啄咬后设为 20。手型摸头按持续接近触发，不要求鼠标按键或移动速度，并以每秒 10 恢复烦躁。以上均为当前默认值，可通过行为参数调整。

首次活动检查在 8 秒；之后间隔 8–20 秒，50% 站立、35% 走路（2–5 秒）、15% 求摸（6 秒）。站立选择可请求短叫，短叫共用 20 秒冷却且不连续重复同一素材。唱歌检查间隔 30 秒，直接互动间隔至少 60 秒、冷却 120 秒，触发概率 20%。纯Core默认持续 3–5 秒；正式宿主接收发声请求后按音频实际播放进度维持动作，当前自然唱段为 4.28 秒，播放结束/取消即收回口型和动作。

自主飞行默认每 90 秒考虑一次，仅在 Idle/Walk、没有手型会话或按住交互、系统空闲超过 2 秒时选择合法平台。上手期间关闭自主选点和地面行走，脚部锚点跟随手指。换手、退出会话或离开主屏安全范围后，按鸟脚到平台最近可站点的欧氏距离排序，跳过无效／遮挡平台，任务栏作为保底；关闭自主探索仍保留离手落点追踪。观察室强制预览与自然策略隔离；Debug 覆盖层可暂停自主选点，但保留跟随和安全回退。

头部先观察后方，较近目标不会带动身体；持续较远后方目标才触发转身。抬头、头部左右角度仍经过稳定时间和中间姿态。增减转身动画帧不会改变这些条件。
