# 玄凤统一造型基准

当前版本依据用户批准的基础版与低像素造型重新制作，正式基准为 `model-sheet.png`。历史候选稿保留本地；生成器在本地输出 `ThreeViews.png`（正面、侧面、背面）和 `TurnAngles.png`（侧视、回头、斜面、正面），预览图不纳入源码发布。

## 唯一基准与实际引用

- `model-sheet.png` 是内置 imagegen 生成的主源图。上排：侧面／正面／背面；下排：斜面／正面闭眼／侧身回头。完整提示词与来源见 [PROMPTS.md](PROMPTS.md)。
- `model.json` 声明格子顺序、统一尺度与运行时绑定。整张稿只计算一次缩放：侧面全身高 41 个原始像素；正面、背面、斜面、回头共用该系数，不能逐格铺满。
- `tools/prepare_model.py` 导出 64×64 标准帧，提供闲置侧面、斜面、正面、眨眼和回头。正面眨眼只替换闭眼局部。
- 水平侧视与闲置侧面逐像素一致。走路复用同一侧面头身，只有脚步和一像素起伏变化；`walk-rig.png` 只提供脚部。
- 转身复用斜面／正面的头身、两侧尾翼，`turn.png` 仅提供中央脚部。水平正视使用 `look.png` 上排中格的完整头颈和身体，避免硬切头部后的颈部断层。回头直接采用模型 rear，导入注视素材时跳过重复回头格。
- `look.png` 的水平正视及三种仰头是独立绘制变体，须在模型更新后人工复核；参考哈希记录在 `asset-bindings.json`。水平正视与伸翅中间帧通过 `paletteGroups` 统一到 idle 的原始灰脸部颜色，不改变姿势。
- 飞行落地末帧按朝向把同一闲置侧面或正面放入 96×96 画布，四周各留 16 像素。正面／侧面飞行分别按各自标准脸颊面积统一尺度；正面用于接近竖直的起落。背面目前只用于模型参考。

## 固定特征与尺度

保留紧凑头骨、靠外侧的黑色眼睛、细长黄色冠羽、橙色脸颊、灰色鸟喙与身体、白色翼斑、细长尾羽和粉色脚。以少量清晰像素块表达，避免换动作后头部变成团子比例。

地面画布 64×64，脚底 y=56。默认足部锚点 x=32；长尾超出左侧时，导出整体平移并同步声明足部锚点，保持身体尺度。显示时必须使用 manifest 中每帧的 foot，不能假定所有帧都在同一 x。飞行画布 96×96，足部锚点在对应站姿基础上加 [16,16]。

低头、仰头、回头会改变冠羽投影和外接高度。应比较头骨、脸颊和肩背比例，不能用姿势的总高度强行拉齐。Beg／Pet 共用 Beg 的缩放系数；飞行使用脸颊面积与侧面基准比较，不能按翅膀展开范围调整全身大小。

## 后续动作流程

1. 以本主源图和批准参考为角色基准生成新动作，保持相同身体及头部尺度。
2. 优先复用相同角度的完整头颈和身体。独立角度需在最终显示尺寸下与标准视图对照；新动作的黄色头部与橙色脸颊须对照 idle 色板，存在偏色时声明 `paletteGroups` 并执行最终校色。
3. 核对动作首末帧及状态切换，尤其侧视进入回头、转身、行走，Beg 切换 Pet，以及降落进入站姿。
4. 更新真实来源、合成声明、人工复核哈希和眼睛／鸟喙区域，执行完整导出及构建；不能只覆盖发布目录 PNG。

当前各帧的实际依赖以自动生成的 [动画引用清单](../actions/ANIMATION_REFERENCES.md) 为准；源图管理与执行步骤见 [ASSET_MANAGEMENT.md](../actions/ASSET_MANAGEMENT.md)。
